## Descripción del Proyecto
API que devuelve recomendaciones de productos para un usuario, usando algoritmos sencillos (basado en tags y ratings).
Debe exponer un endpoint principal:

```agsl

GET /recommendations/{userId}
```

que combine señales de historiales, tags, valoraciones y popularidad.
Existirán otros endpoints, pero este será el principal y tendrá mayor puntuación.

## Metodología de trabajo

## 🛠️ Tecnologías y Herramientas
**Lenguaje:** Java 17+

**Framework:** Spring Boot 2.7+ o 3.x

**Seguridad y autenticación:** Spring Security + JWT

**Base de datos:** PostgreSQL

**Documentación de APIs:** Swagger UI

**Testing de APIs:** Postman + JUnit 5 + Mockito

**Gestión del proyecto:** Taiga

**Control de versiones:** GitHub

**Mappers / Boilerplate:** MapStruct, Lombok

**Contenerización:** Docker

**Build:** Maven o Gradle (elige la que prefieras)
